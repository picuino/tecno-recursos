Vistas
======
Las vistas son dibujos de una figura tridimensional obtenidas desde
distintas direcciones.
Las tres vistas principales que vamos a utilizar son 
el **alzado** (vista de frente), el **perfil** (vista lateral) y
la **planta** (vista desde arriba).

En concreto, vamos a utilizar el sistema europeo, que determina 
una disposición de las tres vistas diferente de la utilizada en el
sistema americano.

Este tipo de representación mediante proyecciones ortogonales se
denomina `sistema diédrico
<https://es.wikipedia.org/wiki/Sistema_di%C3%A9drico>`__.

.. image:: dibujo/_images/dibujo-vistas-perspectivas-f3.png
   :width: 360px

En las siguientes páginas se explican cada una de las tres vistas con
